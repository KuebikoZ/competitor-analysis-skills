# 氢离子功能清单

> **氢离子** —— 可靠的医学AI助手
>
> 出品方：阿里健康 | 氢离子
>
> 获取方式：APP（扫码下载） / 网页端 ali-doctor.com

---

## 一、APP首页

APP首页以搜索框为核心，提供四大功能入口：

| 功能入口 | 说明 |
|---------|------|
| 搜文献 | 精准搜索医学文献 |
| 搜指南 | 精准搜索临床指南 |
| 搜药品 | 精准搜索药品信息 |
| PDF翻译 | 上传PDF进行翻译/总结 |

- 搜索框支持**文字输入、语音输入、图片上传**
- 搜索框下方展示推荐问题示例（如疾病临床表现、用药指导、最新研究进展等）

---

## 二、PC端首页

网页版同步上线：**https://ali-doctor.com**（功能更多，操作方法与APP相同）
搜索框输入：文字、图片
PC端首页四大功能入口：

| 功能入口 | 说明 |
|---------|------|
| 搜文献 | 4000万文献实时更新 |
| 搜指南 | 3W+国内外权威指南 |
| 找药品 | 6W+药品说明书 |
| 上传PDF | AI原文翻译·AI原文总结 |

首页还提供三类推荐示例查询：**药物临床试验**、**临床诊断**、**医学概念**。

---

## 三、智能问答页

在输入框通过文字、语音或上传图片的方式输入问题，进入【智能问答页】，询问各类临床、科研问题，包括**问疾病、问数据、问病例、问药物、找知识、找资源**等。

### 核心功能

| 功能 | 说明 |
|------|------|
| **正文回复** | 所有输出观点均附循证依据，点击正文中的引用角标，即可展开查看支撑该观点的核心文献段落，逐条核验，有据可查 |
| **引用浮层** | 点击引用即可唤出浮层，支持即时翻译、摘要速览/全文查看，并可精准定位原文位置，方便快速核对与深度阅读 |
| **参考来源** | 提供完整参考来源列表，点击任一文献即可一键跳转至详情页阅读原文，完整追溯每条结论的出处与依据 |

---

## 四、精准搜索页

在输入框点击搜文献/搜指南/搜药品后输入问题，进入分类【精准搜索页】，支持**一句话搜索，无需拆分关键词**。

### 核心功能

| 功能 | 说明 |
|------|------|
| **结果列表** | 中文输入，中英文对照输出，与问题相关的关键词自动识别并提示 |

### 界面要素

- 顶部支持切换搜索分类（文献/指南/药品）
- 搜索框提示语：「海量医学文献任意搜...」
- **最新精选**：内容源自权威期刊
- **标签筛选**：RCT、Meta分析、综述、系统性评价、病、筛选等
- 搜索结果展示：英文标题 + 中文翻译 + 期刊标签（如 JAMA、TOP期刊、JCR Q1、中科院1区、IF 值等）+ 发布时间

---

## 五、资源概览页

在【智能问答页】【精准搜索页】点击文献标题，进入【资源概览页】，在线阅读原文，还可将原文下载至知识库，方便随时查看。

### 核心功能

| 功能 | 说明 |
|------|------|
| **原文摘要** | 展示文献摘要，支持自动翻译 |
| **全文AI中文总结** | AI自动生成中文总结 |
| **在线阅读** | 免费在线翻译阅读 |
| **原文链接** | 跳转至原始出版来源 |
| **加入知识库** | 将文献保存至个人知识库 |
| **分享** | 分享文献给他人 |

### 文献信息展示

- 英文标题 + 中文译文
- 作者、发布日期、期刊名称
- 期刊标签（TOP期刊、JCR分区、中科院分区、影响因子等）
- DOI（支持一键复制）

---

## 六、沉浸阅读页

在【资源概览页】点击阅读原文，进入【沉浸阅读页】查看全文翻译、全文AI总结，点击相应段落，**中英文自动联动对照定位**。

### 核心功能

| 功能 | 说明 |
|------|------|
| **原文总结** | 精准提取要点，每条要点均可定位到原文（标注 P1、P2…Pn 段落编号），点击要点自动跳转至对应原文段落 |
| **对照翻译** | 左右分栏，中英文联动对照阅读 |
| **文内搜索** | 快速定位关键词 |

---

## 七、PDF翻译/上传

在【首页】点击 PDF 按钮，上传本地 PDF 文件。

### 核心功能

| 功能 | 说明 |
|------|------|
| **在线阅读原文** | 上传后即可在线阅读PDF内容 |
| **全文翻译** | 支持全文AI翻译 |
| **全文AI总结** | 自动生成中文总结 |
| **自动加入知识库** | 上传后自动保存至知识库，随时在线查看 |

---

## 八、我的知识库

点击侧边栏进入【我的知识库】，统一查看和管理本地上传PDF和在线下载的原文。

### 核心功能

| 功能 | 说明 |
|------|------|
| **APP/PC双端实时联动** | 手机端与电脑端数据实时同步 |
| **自定义文件夹分类管理** | 支持新建知识库，按主题分类管理下载/上传文件 |
| **统一文件管理** | 集中管理所有文献资源 |
| **无缝接力阅读** | 跨设备无缝切换，继续阅读 |

---

## 九、历史记录

在【首页】点击侧边栏（时钟图标），进入历史记录，可分类查看智能问答/精准搜索/沉浸阅读历史信息，一键回顾。

### 分类标签

| 标签 | 说明 |
|------|------|
| **对话** | 智能问答历史记录 |
| **搜索** | 精准搜索历史记录 |
| **阅读** | 沉浸阅读历史记录 |

### 阅读历史标识

| 图标 | 含义 |
|------|------|
| 🟢 绿色书签图标 | 下载的文件 |
| 🔴 红色PDF图标 | 上传的文件 |

支持搜索历史记录。
